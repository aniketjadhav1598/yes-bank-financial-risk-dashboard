# YES Bank Financial Risk Recovery Dashboard

## Project Overview

This Power BI project analyzes YES Bank's financial performance, credit risk exposure, lending behavior, and recovery opportunities using historical financial data.

The dashboard helps understand how Non-Performing Assets (NPAs), profitability trends, external events, and lending activities impacted the bank's financial health and recovery journey.

## Business Problem

YES Bank faced significant financial challenges due to rising NPAs, declining investor confidence, and operational instability.

This project aims to:

* Analyze historical NPA trends
* Measure the impact of major financial events
* Evaluate lending and deposit performance
* Simulate recovery scenarios
* Recommend data-driven recovery strategies

## Key Insights

* Rising NPAs negatively impacted profitability and market confidence.
* External events accelerated financial instability and deposit withdrawals.
* Lending performance weakened during high-risk periods.
* Recovery simulations showed improvement potential through stronger risk controls and transparency.
